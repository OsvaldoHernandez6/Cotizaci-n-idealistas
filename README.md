# Cotización LinkedIn · Ads Not Dead

Página estática con la cotización de estrategia de contenidos y paid media en LinkedIn, con botón de descarga del PDF.

## Archivos

- `index.html`: la cotización navegable (HTML, CSS y JS en un solo archivo).
- `cotizacion-linkedin.pdf`: el PDF A4 que descarga el botón.

## Publicar

Es un sitio estático, sin build. Sube la carpeta al repositorio y despliégala en Vercel (Framework preset: **Other**, sin comando de build) o en GitHub Pages.

El botón descarga `cotizacion-linkedin.pdf` desde la misma carpeta, así que ambos archivos deben quedar juntos.

La página lleva `noindex` para que no aparezca en buscadores.
